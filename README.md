# Constantine’s Travels

A responsive photography site with 16 original travel photographs, themed gallery filters, individual photo pages, related photographs, and Pinterest sharing.

## Publish
GitHub repository Settings → Pages → Deploy from a branch → main → / (root).

Expected public address after Pages is enabled: https://cmoskes.github.io/constantines-travels/

## Update
Edit captions in index.html and photos/photo-XX.html. Keep locations factual. Add genuine first-person stories when supplied by Constantine.

WebP images remove source metadata and use responsive gallery thumbnails. No tracking, dependencies, paid services, or invented affiliate links.
